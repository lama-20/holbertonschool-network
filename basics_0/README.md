# Network Basics 1

This directory contains Bash scripts covering networking fundamentals on Ubuntu.

## Files

| File | Description |
|------|-------------|
| `0-change_your_home_IP` | Configures the server so `localhost` resolves to `127.0.0.2` and `facebook.com` resolves to `8.8.8.8` |

## Concepts

- `/etc/hosts` file and local name resolution
- Loopback interface and `localhost`
- IP addressing
